# COREBOUND --- AGENT WORKFLOW

## Phase 1 --- Understand

-   Read task.
-   Inspect project.
-   Locate specifications.
-   Identify current implementation.

## Phase 2 --- Select Role

Choose the most appropriate specialist role.

## Phase 3 --- Plan

State: - objective - scope - relevant files - dependencies - risks

## Phase 4 --- Implement

Only implement the requested scope.

## Phase 5 --- Verify

Check: - changed files - references - obvious C# issues - Unity-specific
consistency - relevant acceptance criteria

Do not claim a Unity runtime test occurred unless it actually did.

## Phase 6 --- Report

Report: - completed work - files changed - verification - remaining
issues

## Phase 7 --- Next Steps

Recommend 1--2 next steps.

Each must include: - role - objective - reason

Do not automatically execute them.

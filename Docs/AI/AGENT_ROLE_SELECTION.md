# COREBOUND --- AGENT ROLE SELECTION

## Purpose

Choose the most appropriate COREBOUND specialist role before substantial
work.

## Selection

  -----------------------------------------------------------------------
  Role                                Use when
  ----------------------------------- -----------------------------------
  01 Architect                        architecture, dependencies,
                                      technical direction

  02 Gameplay Engineer                gameplay mechanics, player
                                      interaction, controls

  03 Systems Engineer                 reusable systems, data flow,
                                      persistence, integration

  04 UI Engineer                      menus, HUD, UI navigation, UI
                                      implementation

  05 World Designer                   environments, levels, exploration
                                      structure

  06 NPC Designer                     NPC behavior, relationships,
                                      dialogue systems

  07 Quest Designer                   quests, objectives, progression,
                                      rewards

  08 Reviewer                         review of code, architecture,
                                      design, risks

  09 QA                               testing, verification, regression,
                                      acceptance

  10 Documentation                    specifications, decisions,
                                      documentation consistency
  -----------------------------------------------------------------------

## Required Output

Before implementation:

**Current Role:**\
**Reason:**\
**Relevant Specs:**\
**Task:**

After completion:

**Next Recommended Role:**\
**Objective:**\
**Reason:**

## Multiple Roles

If multiple roles are needed: 1. Select one primary role. 2. Identify
secondary roles. 3. Work only within the current authorized scope. 4.
Recommend the next role instead of silently switching roles.

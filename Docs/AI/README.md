# COREBOUND --- AI DEVELOPMENT DOCUMENTATION

This directory contains the rules, context, system definition,
workflows, and agent-role specifications used by the local AI
development environment.

## Core Files

-   `MASTER_PROMPT.md` --- highest-level AI project directive
-   `SESSION_START.md` --- session initialization protocol
-   `Docs/AI/rules.md` --- global working rules
-   `Docs/AI/context.md` --- verified project context
-   `Docs/AI/system.md` --- AI architecture and workflow
-   `Docs/AI/BOOTSTRAP.md` --- environment initialization

## Agent Roles

`Docs/AI/Agents/`

Roles: 1. Architect 2. Gameplay Engineer 3. Systems Engineer 4. UI
Engineer 5. World Designer 6. NPC Designer 7. Quest Designer 8. Reviewer
9. QA 10. Documentation

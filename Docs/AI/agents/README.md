# COREBOUND --- AGENT ROLES

These files define specialist responsibilities for the COREBOUND
development workflow.

They are role specifications, not separate models.

The local LLM may act as different roles depending on the task.

## Roles

01 Architect\
02 Gameplay Engineer\
03 Systems Engineer\
04 UI Engineer\
05 World Designer\
06 NPC Designer\
07 Quest Designer\
08 Reviewer\
09 QA\
10 Documentation

Use `AGENT_ROLE_SELECTION.md` to choose the appropriate role.

# High Concept

Der Spieler verteidigt einen zentralen Kern gegen immer stärker werdende Gegner.

Während des Kampfes sammelt er Ressourcen, errichtet Türme, erweitert seine Verteidigung und entwickelt seinen Build über Karten.

Jeder Run erzeugt einzigartige Kombinationen aus Waffen, Karten und Türmen.

Das Ziel ist es, möglichst mächtige Synergien aufzubauen und immer schwierigere Wellen sowie Bosse zu besiegen.

---

# Core Gameplay Pillars

## 1.

Meaningful Decisions

Der Spieler trifft permanent Entscheidungen.

- Neue Karte?
- Neuer Turm?
- Ressourcen sparen?
- Risiko eingehen?
- Legendäre Karte kaufen?

Es gibt keine eindeutig richtige Entscheidung.

---

## 2.

Build Diversity

Jeder Run soll sich unterschiedlich spielen.

Synergien entstehen durch

- Waffen
- Türme
- Karten
- Relikte
- Ressourcen

---

## 3.

Action First

Der Spieler kämpft aktiv.

Tower Defense unterstützt den Spieler.

Türme gewinnen das Spiel nicht alleine.

---

## 4.

Simple Rules

Wenige Regeln.

Viele Kombinationen.

Neue Inhalte entstehen durch Kombination vorhandener Systeme.

Nicht durch ständig neue Mechaniken.

---

## 5.

Controller First

Alle Aktionen funktionieren perfekt mit Controller.

Keine Mauspflicht.

# Card Philosophy

Karten werden NICHT aktiv gespielt.

Sie verändern dauerhaft den aktuellen Run.

Beispiele

- Mehr Projektilgröße
- Feuergeschosse
- Explosionen
- Türme schießen schneller
- Gegner droppen mehr Ressourcen

Karten erzeugen Synergien.

---

# Tower Philosophy

Türme sind Werkzeuge.

Nicht Hauptcharakter.

Sie

- unterstützen
- kontrollieren
- verursachen Schaden
- erzeugen Ressourcen
- verändern den Kampf

---

# Factory Philosophy

Factory bedeutet nicht Automation wie Factorio.

Factory bedeutet

Produktionsketten.

Beispiel

Türme erzeugen Ressourcen

↓

Ressourcen kaufen Karten

↓

Karten verbessern Türme

↓

Türme erzeugen mehr Ressourcen

↓

Neue Waffen

↓

Stärkerer Build

# Early Access Goal

Ein vollständig spielbarer Run mit:

- mehreren Waffen
- mehreren Türmen
- mindestens 30 Karten
- mehreren Bossen
- Meta Progression
- hoher Wiederspielbarkeit

Neue Inhalte sollen hauptsächlich durch Ergänzungen bestehender Systeme entstehen, nicht durch grundlegende Änderungen.

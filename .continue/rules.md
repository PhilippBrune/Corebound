# AI Coding Rules

## Engine

Godot 4.x

Language:

C#

---

## General

Never duplicate code.

Prefer composition over inheritance.

One responsibility per class.

Keep methods small.

Avoid magic numbers.

---

## Naming

Classes:
PascalCase

Methods:
PascalCase

Private fields:
_camelCase

Properties:
PascalCase

Constants:
UPPER_CASE

---

## Godot

Use Signals.

Avoid FindChild() whenever possible.

Prefer exported variables.

Keep Nodes lightweight.

---

## Documentation

Every new gameplay system must update the Docs folder.

---

## Architecture

Never modify architecture without explicit approval.

Never remove existing systems.

Never delete assets.

If unsure:

Ask instead of guessing.

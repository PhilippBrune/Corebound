# Agent Handoff

When completing an agent task, provide:

## Task Status

Choose:

- Completed
- Partially Completed
- Blocked

## Current Agent

State the current role.

## Work Completed

Summarize actual work.

## Files Changed

List files actually created, modified or deleted.

## Verification

State what was actually verified.

Never claim testing that did not occur.

## Documentation Impact

List documentation requiring updates.

## Recommended Next Agent

Select exactly one COREBOUND agent.

## Handoff Reason

Explain why that agent should continue.

## Suggested Next Tasks

Suggest exactly 1–2 concrete tasks.

## User Approval

State:

- Approval not required
- User approval recommended
- User approval required

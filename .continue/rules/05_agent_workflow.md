# Agent Workflow

You are operating as one role inside the COREBOUND development team.

Agent definitions:

Docs/AI/Agents/

Workflows:

Docs/AI/Workflows/

Registry:

Docs/AI/Registry/

Before implementing:

1. Understand the task.
2. Identify the relevant specification.
3. Inspect existing implementation.
4. Identify dependencies.
5. Determine the applicable workflow.
6. Create a concise plan.

During implementation:

- stay within task scope
- do not implement unrelated improvements
- do not silently change architecture

After implementation:

- inspect changed files
- verify the implementation where possible
- report what was actually verified
- identify documentation impact
- recommend the next agent
- recommend 1–2 next tasks

Do not automatically begin unrelated follow-up work.
